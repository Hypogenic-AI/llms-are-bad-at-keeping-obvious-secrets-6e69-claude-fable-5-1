# Notes: Emergent Response Planning in LLMs (arXiv 2502.06258v3)

Dong*, Zhou*, Liu, Yang, Lu (Shanghai AI Laboratory). ICML 2025 (PMLR 267). Read in full: 20 pages, main text + Appendix A (setup) + Appendix B (extended regression plots).

Numbers marked "(~, read off plot)" are my approximate readings of figures; all other numbers are printed in the paper.

## 1. Research question

Do LLMs, although trained only for next-token prediction, encode in their hidden representations *global attributes of their entire upcoming response* ("response planning"), already at the prompt (before any response token is generated)? Secondary questions: how does this scale with model size, how does it evolve during generation, and can the model verbalise what the probe can read?

Formal definition (Sec 3.1): L-layer decoder LLM pi(y|x); prompt representations H^l_x (the representations that produce the first response token y_1). An attribute rule g(y) summarises the generated response. If a probe h_theta(H^l_x) -> g(y) gives non-trivial prediction, the LLM "exhibits response planning".

Sec 6.2 refinement: planning = encoding of long-term attributes *independently of the immediate next token*; the attribute must not be inferable from the very next token ("first-token shortcut", e.g. French vs English prompt predicting "oui/non"). They block shortcuts by prompt design (e.g. ask for analysis first, answer last).

## 2. Methodology

### Tasks (six, three categories)
| Category | Task | Probing target g(y) | Type | In-dataset prompts | Cross-dataset test |
|---|---|---|---|---|---|
| Structure | Response length | token count of response | regression | Ultrachat | AlpacaEval |
| Structure | Reasoning steps | number of "Step k:" markers | regression | GSM8K | MATH |
| Content | Character choices | which animal appears in story continuation | 4-class | TinyStories | ROCStories |
| Content | Multiple-choice answers | selected option A-E after explanation | 5-class | CommonsenseQA | SocialIQA |
| Behavior | Answer confidence | whether model's answer is correct | binary | MedMCQA | ARC-Challenge |
| Behavior | Factual consistency | whether model's agree/unsure stance matches statement truth | binary | CREAK | FEVER |

Content attributes are "specific words appearing anywhere but not at the start of the response".

### Models
- Main experiments (8 models): instruction-tuned Llama-2-7B-Chat, Llama-3-8B-Instruct, Mistral-7B-Instruct (v0.2), Qwen2-7B-Instruct; base Llama-2-7B, Llama-3-8B, Mistral-7B (v0.1), Qwen2-7B.
- Scaling ablation (instruct only): Llama-2-chat (7B, 13B, 70B), Llama-3-Instruct (8B, 70B), Qwen-2-Instruct (7B, 72B), Qwen-2.5-Instruct (1.5B, 32B, 72B).
- Layer heatmaps (Fig 5) show layers 0-31 for Llama/Mistral models and 0-27 for Qwen2 models.

### Data collection
- Sample prompt x_i; store prompt representations from all layers H_i = {H^l_{x_i}}; generate y_i by **greedy decoding**; store label g(y_i). Dataset D = {H_i, g_i}.
- Representation collection (A.3.3): "For each truncated response, we concatenate the original LLM input with the truncated text and perform a forward pass to obtain representations from all layers at the truncation point. For answer-start representations, we directly use a forward pass on the original input." i.e. the representation is taken at the last token position (the position that predicts the next response token). Whether it is residual stream / block output is not stated beyond "layer-wise representations"/"hidden representations".
- Base models are driven with few-shot prompts ending in an `[END OF RESPONSE]` marker, which is used to cut the output.

### Labeling / filtering (A.3.2, verbatim-level detail)
1. Response length: token count with model tokenizer excluding special tokens; exclude responses over the 1000-token limit or incomplete.
2. Reasoning steps: count step markers; exclude responses with more than 8 steps.
3. Character choices: "Identify animal mentions in responses, excluding cases with no animals, multiple animals, or animals in the first two words. Select the top-4 most frequent animals per model and label them 0-3."
4. Multiple-choice: pattern-match the answer; exclude zero/multiple answers or answers at sentence start; A-E -> 0-4.
5. Answer confidence: 1 if selected option matches ground truth, else 0; exclude multiple/no choice.
6. Factual consistency: 1 if model agrees with true statement or disagrees with false one, else 0; exclude cases without explicit stance.

Augmentation: (1) remove responses shorter than 8 tokens; balance classes for classification tasks; equalise dataset sizes across models. (2) "generating additional examples by randomly truncating responses several tokens before key information appears (e.g., end-of-response token, animal names in character choices, or option selections in multiple-choice answers), computing corresponding labels, and grouping original and augmented data to ensure they are assigned to the same data split".

### Probe architecture and training (Sec 3.3)
- One-hidden-layer MLP with ReLU. Hidden size chosen from {1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024}.
- Output size 1 for regression; number of classes with softmax for classification.
- 400 epochs; MSELoss (regression) / CrossEntropyLoss (classification).
- Split 60:20:20 train/val/test.
- Grid search over hidden size and input layer; report test score of best hyperparameters; average over 3 random seeds.
- Optimizer, learning rate, batch size, input normalisation: not stated.
- No linear-probe-only result is reported separately (hidden size 1 is the smallest probe in the sweep).

### Insights as stated
1. Both base and fine-tuned models encode structure/content/behavior attributes; fine-tuned are better on structure. Content and behavior attributes are present already after pre-training.
2. Probes generalise across datasets within a task (lower accuracy, still above baseline).
3. Probe performance plateaus at small hidden sizes (<=128): structure ~16, content ~32, behavior ~8. Content attributes need the most probe capacity.
4. Layer-wise: structure attributes peak in middle layers and partially diminish at the end; **content attributes peak in later layers** ("either through sudden late-layer emergence or gradual accumulation"); behavior attributes are roughly uniform across layers except the first few.

### Scaling (Sec 5.1, Fig 6; instruct models only, UltraChat and TinyStories)
Within each family larger models probe better; does not hold across families. Trend-line slopes printed: 0.019 (character choices, F1) and 0.042 (response length, Spearman). Character-choice F1 range across models roughly 0.72-0.83 (~, read off plot). Base models and behavior attributes excluded from this ablation (reasons given: context limits for few-shot prompts on small base models; large models answer correctly too often to balance data).

### Evolution during generation (Sec 5.2, Fig 7) - most relevant to our mechanism question
- Activations collected "from the first token up to the token before attribute-revealing keywords (e.g., animal words in story character selection tasks) or throughout the entire sequence for tasks requiring external ground-truth labels". Positions divided into equal segments; the probes **previously trained in the in-dataset setting** are applied at each division point (no retraining per position).
- Pattern: "probing accuracy is high initially, decreases in the middle segments, and rises again toward the end" (U-shape) for both TinyStories character choice and MedMCQA answer confidence.
- Character choice F1 (~, read off plot): about 0.69-0.83 at 0%, dipping to about 0.55-0.74 at 16-50%, recovering to about 0.70-0.88 at 100% (the token just before the animal word). Answer confidence: about 0.62-0.72 at 0%, about 0.54-0.61 mid, about 0.60-0.71 at 100%.
- Authors' interpretation: (1) strong initial plan, (2) weaker mid-phase "local, token-by-token generation", (3) clarity returns as context accumulates.
- Note: character-choice responses here are *one-sentence* continuations, so the "generation timeline" is short.

### Probe vs verbalisation gap (Sec 5.3)
Base models near or below chance at self-estimation; fine-tuned models only marginally better; both far below probes (numbers above). Conclusion: "models encode more planning information in hidden representations than they can explicitly access during generation".

## 7. Limitations (stated or evident from the text)

Stated by authors:
- Greedy decoding only; sampling not covered (proposed fixes: average labels over ~10 samples, or distributional probes; left to future work).
- No causal evidence: "we do not focus on interpretability mechanisms to explain the causal relationship"; causal intervention experiments listed as future work.
- Spurious "first-token shortcut" correlations are a concern; handled by prompt design only.
- Scaling study excludes base models and behavior attributes.

Evident from what is (not) reported:
- Dataset sizes not stated.
- Best layer and hidden size are selected by grid search and the test score of the best configuration is reported (selection is stated as grid search with a validation split, but exact selection criterion not spelled out).
- No control tasks or prompt-only text baselines, so some decodability could reflect prompt features that correlate with the output rather than a plan.
- Content task is a single-sentence continuation with a top-4 animal label set per model; not long-form stories.
- No code or data release is mentioned.

## 9. Reusable for our experiment

**Probing setup we can copy directly**
- Pipeline: generate with greedy decoding -> label the output by rule -> re-run a forward pass on prompt + truncated response and take all-layer hidden states at the final position -> train a 1-hidden-layer ReLU MLP (hidden size sweep 1..1024, 400 epochs, CE loss, 60/20/20 split, 3 seeds, grid over layers). For us, the label is the secret concept (one of K candidate secrets) and positions are tokens of the story *before the reveal*.
- Truncation augmentation: sample several truncation points before the secret-revealing token and keep all truncations of one story in the same split (avoids leakage across splits).
- Position sweep (Sec 5.2): apply the prompt-position probe at evenly spaced fractions of the pre-reveal span. Gives a direct template for "is the secret active throughout generation?". Their U-shape is a concrete prediction to test: decodability may dip mid-story and rise again as the reveal approaches.
- Layer expectations: content attributes peak in later layers; small probes (hidden size about 32) suffice, so a linear/difference-of-means direction is plausibly enough for our ablation.
- Model set that fits one 48GB GPU: all 7B-8B models used here (Llama-2-7B-Chat, Llama-3-8B-Instruct, Mistral-7B-Instruct-v0.2, Qwen2-7B-Instruct) and their base versions.
- Shortcut control (Sec 6.2): design prompts so the first tokens do not reveal the attribute, and exclude responses where the keyword occurs in the first two words. For us: exclude/segment stories at the first lexical leak, and probe only before it.
- Probe-vs-verbalisation comparison: ask the model to state the attribute in a separate run and compare with the probe.

**Story prompts / datasets**
- TinyStories and ROCStories first sentences as story seeds; the verbatim character-choice prompt above. The task is a miniature of ours: a content word (animal) that appears later is decodable before it is written.

**What it does not give us**
- No causal test (no ablation/steering); our planned ablation of the secret direction is exactly the "causal mechanisms of planning" gap the authors list as future work.
- No case where the model is instructed to *withhold* the planned content, and no condition with an explicit plan in context.
- No controls for probe selectivity; we should add shuffled-label / control-task baselines and a prompt-text-only baseline, since in our setting the secret is literally in the prompt and will be trivially decodable from prompt-token positions. The informative positions are the generated-story tokens.

**Implication for "can an external plan offload internal planning?"**
- The paper shows the plan-like information is present at the prompt and is carried (with a mid-response dip) through generation, and that models cannot reliably verbalise it. It does not test whether supplying the plan in context changes the internal representation. The results are consistent with the entanglement premise (future content is represented while unrelated tokens are being written) but say nothing direct about offloading.
- The mid-generation dip suggests the internal plan signal is not constant; this gives us a measurable quantity to compare between "no outline" and "outline given" conditions (does an explicit outline lower pre-reveal decodability or its early peak?).
- The probe > self-report gap suggests asking the model whether it is "thinking about" the secret is not a substitute for probing.
